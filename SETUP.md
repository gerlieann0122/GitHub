# Marketing Video Generator Setup Guide

## Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Set Up API Keys

Create a `.env` file in your project directory:

```env
# Claude API Key (required)
ANTHROPIC_API_KEY=your_anthropic_api_key_here

# Higgsfield API Key (required for actual video generation)
HIGGSFIELD_API_KEY=your_higgsfield_api_key_here
```

**Get your API keys:**
- **Anthropic (Claude)**: https://console.anthropic.com/
- **Higgsfield**: https://app.higgsfield.ai/

### 3. Run the Generator

```bash
python marketing_video_generator.py
```

## Usage Examples

### Generate a Single Marketing Video

```python
from marketing_video_generator import create_marketing_video

result = create_marketing_video(
    product_name="Your Product Name",
    product_description="What your product does",
    target_audience="Who you're selling to",
    video_style="cinematic",  # or: energetic, minimalist, luxury, playful
    model="seedance"  # or: soul, kling
)
```

### Generate Multiple A/B Test Variants

```python
from marketing_video_generator import generate_upc_ad_variants

variants = generate_upc_ad_variants(
    product_name="Your Product",
    product_description="Product description",
    num_variants=3
)
```

## Supported Video Models

- **Seedance 2.0**: Best for cinematic, high-quality marketing videos
- **Soul 2.0**: Great for product showcases and demonstrations
- **Kling 3.0**: Fast turnaround for social media content

## Video Styles

- `cinematic`: High-production, dramatic camera work
- `energetic`: Fast-paced, dynamic movement
- `minimalist`: Clean, modern, focused
- `luxury`: High-end, premium aesthetic
- `playful`: Fun, engaging, conversational

## Workflow

1. **Claude generates the prompt** - Uses AI to create a detailed video prompt tailored to your product and audience
2. **Higgsfield creates the video** - Generates the actual video based on the prompt
3. **You get the result** - Job ID and status for tracking

## Troubleshooting

### "HIGGSFIELD_API_KEY not set"
- Add your API key to `.env` file
- Or set it as an environment variable: `export HIGGSFIELD_API_KEY=your_key`

### "API Error"
- Check your API keys are valid
- Ensure you have sufficient credits on Higgsfield
- Check your internet connection

### No module named 'anthropic'
- Run: `pip install -r requirements.txt`

## Output

The generator returns:
- `product_name`: Your product name
- `video_prompt`: The detailed prompt generated by Claude
- `higgsfield_response`: API response with job ID and status
- `model_used`: Which video model was used
